# Jarvis X

A fully offline, multi-modal, agentic OS with voice, vision, memory, PC automation, and coding capabilities.

## Architecture

- `backend/`: Core backend logic and APIs.
- `frontend/`: Web-based dashboard UI.
- `memory/`: Memory system (SQLite, ChromaDB).
- `models/`: Local AI models (Ollama, Whisper, etc.).
- `plugins/`: Plugin framework and extensions.
- `configs/`: Configuration files.
- `logs/`: Application logs.
- `tests/`: Unit and integration tests.
- `docs/`: Documentation.
